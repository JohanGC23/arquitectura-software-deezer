# Documentación del proyecto Deezer

Toda la documentación académica del proyecto se encuentra dentro de esta carpeta `src`.

## Estructura

```text
src/
├── docs/
│   ├── adr/
│   ├── c4/
│   └── empresa/
├── ENTREGA.md
├── REFERENCIAS.md
└── COMANDOS_GITHUB.md
```

## Contenido

- `docs/adr/`: decisiones arquitectónicas.
- `docs/c4/`: diagramas C4.
- `docs/empresa/`: análisis de Deezer, atributos de calidad, riesgos y tácticas.
- `ENTREGA.md`: resumen de la entrega.
- `REFERENCIAS.md`: fuentes utilizadas.
- `COMANDOS_GITHUB.md`: comandos para crear y subir el repositorio.
